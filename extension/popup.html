Plain-text description of what the agent should do. Saved to this extension's local storage; Phase 2a/2b/3/4 will read it once they exist.

Phase 1 diagnostic

Captures the current tab and runs the on-device object detector end-to-end through background.js and the offscreen document. This is the interactive way to exercise the round trip described in extension/README.md. First run loads the model (Phase 0 measured warm WebGPU inference at ~8.4s -- this can take noticeably longer, be patient). 



  


  
Full agent loop

  

    Runs the complete capture → detect → scan → redact →
    send → act loop against the CURRENT tab, up to 25 steps or until the
    agent reports "done". Requires the FastAPI server running and reachable
    at the Server URL configured under Settings below. Live progress
    (step, stage, last action, any blocked/refused action, and any error)
    is shown here as the loop runs -- the page's own DevTools console still
    has the full per-stage instrumentation and the Section 5 payload check,
    for anyone who wants that level of detail.
  

  
  
  

  


  


  
Settings

  

    Server URL for the FastAPI backend (default http://localhost:8000).
    Must be within this extension's permitted hosts
    (http://localhost/*, http://127.0.0.1/*) --
    Chrome blocks anything else at the network layer regardless of what is
    typed here. Using a different host requires widening
    manifest.json's host_permissions and
    reloading the extension; that is a separate, deliberate decision, not
    something this field can do on its own.

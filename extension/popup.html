        Settings
        

          

            Server URL for the FastAPI backend (default http://localhost:8000).
            Must be within this extension's permitted hosts (http://localhost/*,
            http://127.0.0.1/*) — Chrome blocks anything else at the
            network layer regardless of what's typed here.
          

          
          
          


          

            Full-page capture: scroll the page in steps and stitch the captures into one
            image before detection, instead of the visible viewport only. Default
            off (viewport-only remains the known-good fallback). Slower per step
            and uses more memory — see the RUN SUMMARY's fullPage fields
            for real numbers on a given page.
          

          
          

        

      


      
      

        Your profile (autofill)
        

          

            Saved here stays on this device in this browser's local extension
            storage. The model never sees it and it is never sent to the server — when a page
            wants one of these fields, the model only ever names which category it wants
            (e.g. “email”), and this extension fills the value in locally. That is what
            lets the agent autofill a field it would otherwise have to refuse.
          

          
          
          
          
          
          
          
          

        

      


      

        Advanced diagnostics
        

          

            Captures the current tab and runs the on-device object detector end-to-end
            through background.js and the offscreen document — a developer diagnostic,
            not something normal use needs. First run loads the model and can take much
            longer than later runs.

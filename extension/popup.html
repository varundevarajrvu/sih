Task Goal

Plain-text description of what the agent should do. Saved to this extension's local storage; Phase 2a/2b/3/4 will read it once they exist.

Phase 1 diagnostic

Captures the current tab and runs the on-device object detector end-to-end through background.js and the offscreen document. This is the interactive way to exercise the round trip described in extension/README.md. First run loads the model (Phase 0 measured warm WebGPU inference at ~8.4s -- this can take noticeably longer, be patient). 



  


  
Phase 4: full agent loop

  

    Runs the complete capture → detect → scan → redact →
    send → act loop against the CURRENT tab, up to 6 steps or until the
    agent reports "done". Requires the local FastAPI server running at
    http://localhost:8000 (see demo/README.md).
    Open the page's own DevTools console (not this popup's) BEFORE
    clicking -- all instrumentation and the Section 5 payload check are
    logged there, not here.
